# אתר בית הכנסת "השמחה שבאופק"

אתר סטטי (HTML/CSS/JS ללא צורך בשרת) המציג את זמני תפילת הנץ החמה (ותיקין)
בבית הכנסת "השמחה שבאופק", קהילת אוהב ישראל, נתיבות.

## מבנה הפרויקט

```
index.html      - עמוד הבית
zmanim.html     - לוח זמנים חודשי של הנץ החמה ותחילת התפילה
shabbat.html    - עמוד שבת קודש (לעדכון שבועי ידני)
css/style.css   - העיצוב
js/zmanim.js    - חישוב אסטרונומי של הנץ החמה + בניית הלוחות
js/common.js    - תפריט נייד ושנה בפוטר
images/         - יש למקם כאן logo.png ו-favicon.png
```

## איך פועל חישוב הזמנים

הזמנים מחושבים ישירות בדפדפן (ללא צורך בשרת/API חיצוני), לפי נוסחאות אסטרונומיות
סטנדרטיות (NOAA), עבור קואורדינטות נתיבות (`31.4231, 34.5878`), עם זנית 90.833°
- בדיוק כמו אפשרות "זריחה הנראית" באתר chaitables.com.
תחילת התפילה מחושבת כ-18 דקות לפני ההנץ. ניתן לשנות מספר זה בקובץ
`js/zmanim.js` במשתנה `MINUTES_BEFORE_HANETZ`.

## לפני העלאה לאוויר

1. הוסיפו את קובץ הלוגו לתיקיית `images` בשם `logo.png` (וגם `favicon.png` אם רוצים).
2. אפשר לפתוח את `index.html` ישירות בדפדפן כדי לבדוק את האתר מקומית.

## איך מעלים את האתר לאינטרנט (חינם, ללא צורך בשרת)

**אפשרות מהירה - Netlify Drop:**
1. גשו לכתובת https://app.netlify.com/drop
2. גררו את כל תיקיית הפרויקט לתוך הדפדפן.
3. תוך שניות תקבלו קישור פעיל לאתר.

**אפשרות דרך GitHub Pages:**
1. צרו מאגר (repository) חדש ב-GitHub והעלו אליו את כל הקבצים.
2. בהגדרות המאגר (Settings → Pages) בחרו את הענף `main` כמקור לפרסום.
3. האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-המאגר>/`.

## הוספת דפים בעתיד

כדי להוסיף עמוד חדש - יש להעתיק את מבנה ה-header/footer מאחד הדפים הקיימים,
ולהוסיף קישור אליו בתפריט הניווט (`.main-nav`) בכל אחד מהדפים.
